# راهنمای افزودن پروژه جدید

از این به بعد هیچ‌وقت لازم نیست `index.html` را دست بزنید. فقط کافیست
یک فولدر جدید این‌جا (داخل `projects/`) بسازید — سایت خودش موقع دیپلوی
(هر بار push می‌کنید) آن را پیدا می‌کند.

## ساختار یک پروژه

```
projects/
  my-new-project/
    index.md      ← الزامی
    cover.jpg      ← عکس اصلی (اختیاری، ولی توصیه می‌شود)
```

نام فولدر همان چیزی است که در آدرس عکس استفاده می‌شود، پس بهتر است
لاتین، بدون فاصله و با خط تیره باشد (مثلاً `orbit-collective`).

## فایل index.md

```markdown
---
title: ORBIT COLLECTIVE
client: Placeholder Client
year: 2024
role: Identity, Type
category: LOGOS
order: 1
cover: cover.jpg
link: https://example.com/watch
tag: XR / AUGMENTED REALITY / 2025
label_overview: OVERVIEW
label_contribution: CONTRIBUTION
clients:
  - Client One
  - Client Two
roles:
  - Role One
  - Role Two
---

## Overview
یک پاراگراف درباره‌ی خود پروژه. **Markdown** ساده (بولد، ایتالیک،
[لینک](https://example.com)) پشتیبانی می‌شود؛ فعلاً هر بخش را در یک
پاراگراف بنویسید.

## Contribution
یک پاراگراف درباره‌ی نقش/رویکرد شما در پروژه.

## Credit
اختیاری — مثلاً «طراحی‌شده زیر نظر [نام](لینک) در استودیوی X».
```

### توضیح فیلدها

| فیلد | الزامی؟ | توضیح |
|---|---|---|
| `title` | بله | عنوان پروژه |
| `category` | بله | باید دقیقاً یکی از مقادیر `key` در `categories.json` باشد (`LOGOS`, `POSTERS`, `3D`, `XR`, `MOTION`) |
| `client` | خیر | نام کارفرما |
| `year` | خیر | سال |
| `role` | خیر | نقش/تخصص |
| `order` | خیر | ترتیب نمایش داخل همان دسته (عدد کوچک‌تر = بالاتر). اگر ننویسید، بر اساس جدیدترین سال مرتب می‌شود |
| `cover` | خیر | نام فایل عکس اصلی. اگر ننویسید، اسکریپت خودش دنبال فایلی به اسم `cover.*` یا اولین عکس داخل فولدر می‌گردد |
| `link` | خیر | لینک «WATCH» که روی کارت پروژه نمایش داده می‌شود |
| `tag` | خیر | برچسب بالای صفحه‌ی جزئیات (اگر ننویسید خودکار ساخته می‌شود) |
| `label_overview` / `label_contribution` | خیر | عنوان دو بخش (پیش‌فرض: BRIEF / APPROACH) |
| `clients` / `roles` | خیر | لیست چند‌تایی، برای پروژه‌هایی با چند کارفرما/نقش |

بخش‌های `## Overview` و `## Contribution` الزامی نیستند ولی اگر خالی
بگذارید، آن قسمت در سایت خالی نمایش داده می‌شود. بخش `## Credit`
اختیاری است.

## عکس‌ها

هر فرمت `.jpg .jpeg .png .webp .gif` پشتیبانی می‌شود. اگر هیچ عکسی
نگذارید، همان جلوه‌ی گرافیکی نمادین (procedural art) که برای پروژه‌های
placeholder فعلی می‌بینید به‌جایش نمایش داده می‌شود.

## بعدش چیکار کنم؟

فقط `git add`, `git commit`, `git push`. حدود یکی-دو دقیقه بعد از
push، GitHub Action خودش پروژه‌ها را اسکن می‌کند، `projects.json` را
می‌سازد و سایت را دوباره منتشر می‌کند — کار دیگری لازم نیست.

می‌توانید پیشرفتش را در تب **Actions** مخزن‌تان دنبال کنید.
